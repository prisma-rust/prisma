# Multi-platform virtual geometry architecture design (Beyond-Nanite Cluster-DAG / soft-hard hybrid rasterization / ray tracing same-origin)

> **Tier**: L2 subsystem design contract · Rendering advanced
> **Status**: M1–M3 (including `MeshCooker` access) and M5/M6 core math and runtime landed (`prism-asset` / `prism-cooker` / `prism-render`); M4 offline Slang shaders pending `slangc` host environment compile/sign-in
> **Related**: [DESIGN.md](DESIGN.md), [rtx-dlss-integration-design.md](rtx-dlss-integration-design.md), [prt-gi-64tree-design.md](prt-gi-64tree-design.md), [mobile-raytracing-gi-design.md](mobile-raytracing-gi-design.md)

This document defines Prisma engine's unified virtual geometry (Virtual Geometry) rendering architecture targeting **latest desktop flagship GPUs (NVIDIA RTX 40/50, AMD RDNA 3.5/4) and mobile flagship SoCs (Snapdragon 8 Gen 3 / 8 Elite Adreno 750/850+, Dimensity 9400 Immortalis-G925)**. Inheriting traditional Nanite's "Cluster-DAG level-less automatic LOD + VisBuffer zero Quad Overdraw" advantages, while focusing on overcoming traditional solutions' structural shortcomings in **hardware ray tracing geometry non-same-origin, dynamic skeletal skinning, high-frequency vegetation degradation, offline package bloat, and mobile TBDR bandwidth wall** five domains.

---

## 0. Design positioning and multi-platform hardware tier matrix

Following [`DESIGN.md`](DESIGN.md) §2.1 and §2.5–§2.6 iron laws, all platforms maintain only **one virtual geometry RenderGraph topology and data format**, strictly prohibit writing `#[cfg(target_os)]` render branches. Differences fully converge to `VirtualGeometryCaps` and `VirtualGeometryTier` probed by `crates/prism-render/src/capabilities.rs` at initialization:

| Tier | Enum ID | Target hardware representative | Probed core extensions and features | Pipeline execution path |
|------|---------|-------------------------------|-------------------------------------|-------------------------|
| **Tier 0** | `NextGenClasMeshSw` | RTX 40/50 Blackwell, RX 9000 | `VK_EXT_mesh_shader` + `shaderBufferInt64Atomics` + `VK_NV_cluster_acceleration_structure` (CLAS) + `VK_NV_displacement_micromap` (DMM) + `VK_EXT_opacity_micromap` (OMM) | **Subgroup DAG culling → Task/Mesh Shader (≥ 4 px²) + 64-bit Atomic soft raster (< 4 px²) → CLAS hardware cluster-level ray tracing same-origin → DLSS-RR / DLSS-G** |
| **Tier 1A** | `FlagshipMeshSw` | Snapdragon 8 Gen 3 / 8 Elite (Adreno 750/850+), Dimensity 9400 (Immortalis-G925), mainstream discrete GPUs | `VK_EXT_mesh_shader` + `shaderBufferInt64Atomics` + Subgroup + `VK_KHR_ray_query` (no CLAS) | **Subgroup DAG culling → Task/Mesh Shader + 64-bit soft raster mixed → Active-Cut dynamic cluster BLAS pool → Adreno ANF / NRD / SGSR2** |
| **Tier 1B** | `TileLocalSubpass` | Modern mobile SoCs supporting Tile Image / strong TBDR (no 64-bit Atomics or prioritize on-chip bandwidth) | `VK_EXT_shader_tile_image` or Transient Subpass + `VK_EXT_mesh_shader` / `drawIndirectCount` | **Same DAG culling → `TRANSIENT_ATTACHMENT` VisBuffer (Subpass 0) → on-chip GMEM/TLS parse shading (Subpass 1, zero main-memory intermediate bandwidth) → ANF / TAA** |
| **Tier 2** | `IndirectIndexedFallback` | Mainstream Vulkan 1.2 devices, integrated GPUs, CI `llvmpipe` | `bufferDeviceAddress` + `descriptorIndexing` + `drawIndirectCount` | **Same DAG culling → `vkCmdDrawIndexedIndirectCount` → 32-bit VisBuffer → Analytic Resolve → TAA** |

> **Zero compatibility discipline**: per [`versioning.md`](versioning.md) spec, `.rcld` format and runtime structure adopt single latest version from day one, no historical version compatibility branches or degradation shims retained.

## 1. Data contract: `.rcld` (`RCLD` v1 64 KB paged virtual geometry)

`.rcld` is pure little-endian binary format, byte spec defined by `crates/prism-asset/src/formats_virtual_geo.rs` and generated by `crates/prism-cooker/src/cooker/virtual_geo.rs`. Runtime package supports per-page `pread` streaming via `.pak`'s `FLAG_STREAMED` (see [`DESIGN.md`](DESIGN.md) §10.6), zero CPU decode/resort.

### 1.1 Overall layout and constant constraints

| Constant | Value | Description |
|----------|-------|-------------|
| `RCLD_MAGIC` | `b"RCLD"` | 4-byte magic |
| `RCLD_VERSION` | `1` | Format version |
| `RCLD_PAGE_SIZE` | `65536` (64 KiB) | Single page upper limit, friendly with VRAM sub-alloc pages and OS page alignment |
| `RCLD_MAX_CLUSTER_VERTICES` | `128` | Single cluster vertex count hard upper limit |
| `RCLD_MAX_CLUSTER_TRIANGLES` | `128` | Single cluster triangle count hard upper limit (local index `u8x3`, VisBuffer `TriID` occupies 7 bit) |
| `RCLD_MAX_CLUSTER_BONES` | `8` | Single cluster local bone palette upper limit |

File physical layout:

```text
[ RcldHeader: 64 bytes ]
[ PageDescriptorTable: page_count × 20 bytes ]
[ ClusterGroupTable: group_count × 48 bytes ]
[ Page Payloads (Page 0 Resident Root | Page 1..N Streamed Child Pages) ]
```

### 1.2 `RcldHeader` (64 bytes)

| Offset | Size | Field | Description |
|--------|------|-------|-------------|
| 0 | 4 | `magic` | `b"RCLD"` |
| 4 | 1 | `version` | `1` |
| 5 | 1 | `flags` | bit0: `SKINNED`; bit1: `HAS_DMM`; bit2: `HAS_SPLATS`; bit3: `GEOMORPHING` |
| 6 | 2 | `max_lod_level` | DAG maximum level count |
| 8 | 4 | `page_count` | Total page count (Page 0 is always resident Root Page) |
| 12 | 4 | `group_count` | `RcldClusterGroup` total count |
| 16 | 4 | `cluster_count` | `RcldCluster` total count |
| 20 | 4 | `root_group_index` | Coarsest root group index |
| 24 | 12 | `bounds_min` | `[f32; 3]` asset local space min bounding box |
| 36 | 12 | `bounds_max` | `[f32; 3]` asset local space max bounding box |
| 48 | 4 | `page_table_offset` | Page table byte offset (fixed `64`) |
| 52 | 4 | `group_table_offset` | Group table byte offset |
| 56 | 4 | `payload_offset` | Page payload start offset |
| 60 | 4 | `reserved` | Zero, aligned to 64 bytes |

### 1.3 Page descriptor (`RcldPageDescriptor`) and cluster group (`RcldClusterGroup`)

1. **`RcldPageDescriptor` (20 bytes)**:
   - `page_index (u32)`, `byte_offset (u32)`, `byte_size (u32)`, `first_cluster (u32)`, `cluster_count (u16)`, `lod_level (u8)`, `flags (u8)` (bit0 = `RCLD_PAGE_FLAG_RESIDENT_ROOT`).
   - Page 0 is uploaded to GPU `PagePool` immediately on asset mount and permanently pinned (Pinned), ensuring every frame always has available geometry fallback while high-precision page is still streaming, **completely eliminating holes**.
2. **`RcldClusterGroup` (48 bytes)**:
   - `group_id (u32)`, `lod_level (u8)`, `primitive_kind (u8)`, `child_group_count (u16)`, `page_index (u32)`, `child_group_first (u32)`, `first_cluster (u32)`, `cluster_count (u16)`, `reserved (u16)`, `parent_error (f32)`, `self_error (f32)`, `bounding_sphere ([f32; 4])` (xyz = center, w = radius).
   - **Hard invariant**: for any non-root Group, always `parent_error > self_error` and all clusters in same group share exactly the same outer boundary vertex set, guaranteeing under any DAG Cut cut **100% zero topology crack (Crack-Free)**.

### 1.4 Three-modal cluster payload and 20-byte extreme quantization vertex

Each `RcldCluster` carries three frontier geometry primitives according to `primitive_kind`:

| `VirtualGeoPrimitiveKind` | Applicable scenario | Payload content |
|---------------------------|---------------------|-----------------|
| `Triangles (0)` | General rigid / skeletal surface | `QuantizedClusterVertex[N]` (20 B/vertex) + `u8[3][M]` local triangle indices + `normal_cone ([f32; 4])` + 8-Bone palette |
| `DisplacedMicroMesh (1)` | Scan-level high-precision surface, dynamic deformation terrain | Base control triangles (≤ 64) + `i16` 11-bit scalar micro-displacement array, runtime executes $4^k$ barycentric subdivision by screen edge length via Mesh Shader (or direct `VK_NV_displacement_micromap`), package further reduces $6\times \sim 10\times$ |
| `SggxGaussianSplats (2)` | Mid-far vegetation crown, grass sea, hair | Anisotropic 3D Gaussian microfacets (`center[3]`, `scale[3]`, `rotation[4]`, 6-component `sggx_cov[6]`, `opacity`), seamless switch from near-scene OMM hollow triangles to SGGX micro-thin sheet scattering |

**20-byte `QuantizedClusterVertex` layout** (vs traditional `Vertex` (`crates/prism-render/src/mesh.rs`) 60 bytes, compressed **66.7%**):

| Field | Type | Bytes | Description |
|-------|------|-------|-------------|
| `pos_q` | `[u16; 3]` | 6 | 16-bit normalized position relative to cluster local AABB |
| `normal_oct` | `[i8; 2]` | 2 | Octahedral unit normal quantized |
| `tangent_angle` | `i8` | 1 | Tangent frame rotation angle (sign bit encodes handedness) |
| `bone_local_pair` | `u8` | 1 | Local palette main/sub bone index packed (`hi4 \| lo4`) |
| `uv_f16` | `[u16; 2]` | 4 | IEEE-754 half-float UV0 |
| `geomorph_delta_q` | `[i16; 3]` | 6 | Continuous Geomorphing residual vector $\Delta \mathbf{p}$ pointing to parent simplified surface target position |

## 2. Offline build pipeline (`prism-cooker::cooker::virtual_geo`)

Offline build strictly resides in build-time crate `crates/prism-cooker` (`crates/prism-cooker/src/cooker/mod.rs`), controlled by `CookProfile.mesh.virtual_geometry` (`crates/prism-cooker/src/cooker/profile.rs`), **never enters `prism-app` player dependency tree**.

1. **Morton 3D spatial reordering and 128V/128T Meshlet splitting**: sort by triangle centroid Morton Z-order, greedily gather triangles sharing vertices into 128 vertex / 128 triangle upper limit, compute local AABB, bounding sphere, normal cone (`axis.xyz + sin_half_angle`), and 8 local bone palette.
2. **Shared edge graph clustering (Cluster Grouping)**: cluster 4–8 same-level clusters into single `RcldClusterGroup` based on inter-cluster shared edge weights.
3. **Lock-boundary QEM simplification and continuous Geomorphing encoding**:
   - Detect vertices landing on group outer boundary (edges only appear on group-internal single side, or on original model outer boundary) and force lock (`locked = true`);
   - Execute Garland–Heckbert quadratic error metric (QEM) edge collapse only on group-internal edges, target halving triangle count (≈ 50%);
   - Record each collapsed vertex $v$ final target position $\mathbf{p}_{\text{target}}$, write $\Delta \mathbf{p} = \mathbf{p}_{\text{target}} - \mathbf{p}_v$ to `geomorph_delta_q`;
   - Force monotonic error increase: $\varepsilon_{\text{parent}} = \max(\varepsilon_{\text{qem}}, \max_{c \in \text{children}} \varepsilon_c + 10^{-4})$.
4. **Cross-modal proxy generation and 64 KB paging packaging**: when `alpha_masked_foliage` enabled and entering high coarse LOD, auto-fit `SggxSplatPrimitive`; then split by hierarchy and spatial locality into `RCLD_PAGE_SIZE` (64 KiB) physical pages.

## 3. Runtime GPU driver pipeline (`prism-render::virtual_geo`)

### 3.1 `SceneScope` 64 KB Page Pool and ray-driven streaming

- Reuse `crates/prism-render/src/suballocator.rs` to manage fixed-budget global `PagePool` (desktop default 256 MiB = 4096 pages, mobile default 64 MiB = 1024 pages).
- **Zero-hole page fault fallback (Seamless Parent Fallback)**: when GPU/CPU traversing DAG needs to access non-resident child page, immediately submit page fault request to `PageFeedbackRing` (distinguish raster high-priority `RasterCut` and ray tracing reflection request `RayTracingHit { cone_width }`), while this frame automatically renders already resident parent group.
- **LRU eviction**: Page 0 permanently locked, non-root pages execute O(1)/LRU eviction by `last_used_frame` and asynchronously upload new pages via `StagingArena`.

### 3.2 Upscaler-aware DAG cut equation and two-phase HZB culling

1. **Upscaler-aware error threshold**:
   Combine current render mode and internal resolution scale ratio from [rtx-dlss-integration-design.md](rtx-dlss-integration-design.md), `crates/prism-render/src/anf.rs`, `crates/prism-render/src/mobile_upscaler.rs`, dynamically tighten screen error threshold $\tau_{\text{effective}}$:
   $$\tau_{\text{effective}} = \max\left(0.25,\ \tau_{\text{base}} \cdot \frac{H_{\text{internal}}}{H_{\text{output}}} \cdot 2^{\text{lod\_bias}}\right)$$
   Ensure after enabling DLSS Performance / Adreno ANF / SGSR2, reconstructed high-frequency geometry edges still reach native 4K / QHD sharpness.
2. **Continuous Geomorphing blending factor**:
   $$\alpha = \text{saturate}\left(\frac{\varepsilon_{\text{screen}} - \tau_{\text{effective}}}{\tau_{\text{effective}} \cdot \text{morph\_window}}\right), \quad \mathbf{p}_{\text{morph}} = \mathbf{p}_{\text{self}} + \alpha \cdot \Delta \mathbf{p}$$
3. **Quadruple cascade culling and two-phase HZB**:
   - Frustum culling (following `crates/prism-render/src/culling.rs` right-hand Vulkan `[0, 1]` depth convention) → normal cone backface culling → sub-pixel micro-cluster culling → **two-phase HZB occlusion culling** (Phase 1 uses Prev-HZB to cull, occluded candidates queued; Phase 1 after raster generates Curr-HZB, Phase 2 re-tests and redraws newly exposed clusters, zero flicker, zero missing draw).

### 3.3 Soft-hard hybrid rasterization and analytic derivative VisBuffer

- **Automatic area-based routing**:
  - Average projected area ≥ 4.0 px² triangle cluster: routed to **Task/Mesh Shader** (Tier 0/1) or `vkCmdDrawIndexedIndirectCount` (Tier 2), output `32-bit VisBuffer = (visible_cluster_idx << 7) \| tri_idx`;
  - Sub-pixel micro-triangle cluster average projected area < 4.0 px²: on devices supporting `shaderBufferInt64Atomics` routed to **Compute 64-bit soft raster**, via `InterlockedMax` atomic write `64-bit VisBuffer = (reverse_z_depth_bits << 32) \| vis32`;
  - `SggxGaussianSplats` cluster: routed to dedicated Splatting queue, execute elliptical projection and SGGX anisotropic transmission shading.
- **Analytic derivative reconstruction (zero $2\times 2$ Quad Overdraw)**:
  `AnalyticBarycentrics` directly computes perspective-corrected barycentric weights $(\lambda_0, \lambda_1, \lambda_2)$ and analytic screen derivatives $(\partial \lambda / \partial x, \partial \lambda / \partial y)$ for any screen pixel, so without relying on hardware pixel Quad can precisely compute texture gradient `ddx(uv)` / `ddy(uv)`, fed to `crates/prism-render/src/bindless.rs` `SampleGrad` and `assets/shaders/slang/scene_frag.slang` PBR shading pipeline.
- **Geomorphing motion vector deghosting**:
  Analytic stage explicitly computes geomorphing blended position difference between last frame and current frame, removes it from screen-space motion vector before writing to `FORWARD_VELOCITY_H` / `PT_VELOCITY_H`, ensuring **DLSS-RR, Adreno ANF, and TAA** zero ghosting / zero dragging during continuous LOD transition.

## 4. Raster / ray tracing geometry same-origin and neural upscaling interface contract

1. **Active-Cut ray tracing same-origin (Unified Cluster-BLAS / CLAS)**:
   - `ActiveCutClusterList` produced by GPU DAG culling simultaneously serves as ray tracing input source: on Tier 0 via `VK_NV_cluster_acceleration_structure` directly assembles hardware CLAS; on Tier 1 incrementally maintains Active-Cut cluster BLAS pool and attaches to main TLAS, letting `crates/prism-render/src/pt_pass.rs`, `crates/prism-render/src/restir_gi.rs`, and `crates/prism-render/src/sharc.rs` fully align with main view high model, eliminating self-shadow fracture and low-model reflection penetration.
2. **Guide Buffer contract alignment**:
   - VisBuffer Resolve Pass outputs full Guide Buffers (`FORWARD_DEPTH_H` / `FORWARD_NORMAL_H` / `FORWARD_VELOCITY_H` and corresponding `PT_*` handles) per [rtx-dlss-integration-design.md](rtx-dlss-integration-design.md) §3 semantics, no extra full-resolution pre-render pass needed.
